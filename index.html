Playnite Remote

Android client for playnite-bridge

Browse, filter, launch and manage your Playnite library from your phone. Offline-friendly, PC-friendly, no queueing server.

Download latest APK All releases Source on GitHub

Install

  1. Download the APK above (or from the Releases page).
  2. Allow "Install unknown apps" for your browser/file manager.
  3. Install and open; enter your PC's bridge URL + token.

Features

  • Full faceted offline filters (source, platform, genre, tag, category, completion status, score range)
  • Game details, achievements, activity timeline, stats
  • Offline cache + full-offline mode, cover art with ETag/304
  • Client-side collections, per-game notes, share, haptics
  • Themes, persisted settings, export/import settings (JSON)
  • Android TV / controller navigation, home-screen widget, adaptive icon

Bridge

Requires the hardened playnite-bridge plugin (v1.6.0+) installed in Playnite.

Playnite Remote is open source. See the repository for build instructions.
